# Maintenance Management System (MMS)

A professional desktop Maintenance Management System built with Python, PySide6 and SQLite.

## Features

- Login System
- Dashboard
- Asset Management
- Work Orders
- Preventive Maintenance
- Inventory
- Technicians
- Suppliers
- Reports

## Technologies

- Python 3.11+
- PySide6
- SQLite
- Qt Designer
